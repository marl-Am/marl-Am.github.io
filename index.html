Docker Documentation RAG Assistant

An AI-powered search tool utilizing Retrieval-Augmented Generation (RAG) to query official Docker documentation, providing context-grounded, source-cited answers for containerization workflows.

LlamaIndex ingests Docker's own machine-readable documentation export, chunking it into markdown-aware segments and converting them into searchable vector embeddings. The full corpus: 1,413 documentation pages split into 14,813 indexed chunks.

These embeddings are stored in ChromaDB for high-speed, local retrieval, embedded and queried entirely on CPU with no GPU acceleration, on consumer laptop hardware.

When you submit a query, LlamaIndex retrieves the most relevant documentation chunks from ChromaDB to ground the answer, and every response is returned with the specific Docker doc pages it drew from, deduplicated by source.

Ollama generates the answer from that retrieved context using a local model, so no query or document content ever leaves the machine.

The retrieval and generation pipeline lives behind a shared service layer with a validated request and response schema, rejecting empty or oversized input before it reaches the model, so the same indexed knowledge base can be queried through either interface without duplicating setup or reloading the index twice.

Chainlit and a plain FastAPI JSON API are mounted in a single process and both consume that shared pipeline directly, keeping the interactive chat experience and the underlying search logic decoupled from each other while avoiding the overhead of a network hop between them. Covered by a 71-test suite spanning ingestion, retrieval, and both interfaces.

Email Signature Management Platform

A SaaS tool for creating, customizing, and tracking professional email signatures, with pixel-based open tracking and click analytics built in. Authentication runs on Argon2id password hashing, and every route enforces ownership-based access control at the application layer. A user can only ever view or modify their own signatures and analytics data. Server-rendered with Jinja2 and Alpine.js, containerized with Docker, deployed through a continuous pipeline (GitHub Actions CI, auto-deploy on Render).
